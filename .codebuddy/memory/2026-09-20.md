# 2026-09-20 定稿 v7：gps_test_coldstart（北云+华测，切片+室内/室外双模式+HMI，报告按启动配对排序）

## 目录结构
- `BY_coldstart.py`（北云 #BESTGNSSPOSA）/ `HUACE_coldstart.py`（华测 #BESTPOSA）/ `gnss_coldstart_hmi.py`（HMI）
- `coldstart_split.py`（静态切片，非大模型）/ `indoor_coldstart.py`（室内联合分析，两家配对对齐 t0）
- `by_data\com3.dat`（46MB，连续录制，9 次干净冷启动）；`huace_data\冷启动室内-室外143827_M720_COM11.log`（36MB，9 次）

## 冷启动切片（coldstart_split.split_coldstart，静态确定性，无猜测）
- 北云 mode='week_reset'：GPS 周回落（默认周→真实周）识别启动；有效冷启动 = 首帧 Time Status = UNKNOWN（时钟全丢、默认周）。
- 华测 mode='time_gap'：相邻报头时间差 >5×标称周期识别启动；有效冷启动 = 首帧 ∈ {UNKNOWN, APPROXIMATE}。
- 干净冷启动判据（用户确认）：断电无电池、时钟全丢 → 首帧必须默认时间/未知态；北云 FREEWHEELING（带真实周）、华测 FINESTEERING（已有解）的段 01 不算，排除。
- 两家均 9 次干净冷启动，时间戳边界一一对应；编号从 cold01 连续（analyze_file 内 enumerate(cold,1)）。

## 室内/室外双模式（HMI 必选单选）
- 室外冷启动（默认）：t=0=启动时刻（日志起点），全程计入；两家各自独立分组、独立出报告。
- 室内冷启动：需北云+华测各 1 个连续录制文件（按启动序号一一配对：北云 coldNN ↔ 华测 coldNN）；
  共同 t0 = 两家最早"拿到时标"的时刻（取较小者），t0 前数据（室内移动过程）丢弃；
  各自统计四阶段，出一份联合对比报告（indoor_coldstart.py）。
- "拿到时标"判定：北云 Time Status 首次 != UNKNOWN；华测 首次 not in {UNKNOWN, APPROXIMATE}（coldstart_split.first_valid_time_offset）。
- build_raw 支持 t0_shift 参数：时间轴左移并丢弃 t<0 帧。
- 联合报告标题通用化（"室内冷启动联合分析（北云 UG016 + 华测 M720）"），make_images 支持 title_prefix。
- 报告/图表排序（v7）：make_images 与 build_outputs 用 sort_for_report()，键=(segment.index, 产品序, file)，
  同一次启动相邻（北云_cold01、华测_cold01、北云_cold02、华测_cold02……）；
  单产品（无 segment.index）退化为纯文件名排序。indoor_coldstart.run() 的 data 顺序本身即配对穿插。

## HMI（gnss_coldstart_hmi.py）
- 文件列表两列（文件名/产品类型）；下拉先选产品再加文件，报文特征校验（北云须含 #BESTGNSSPOSA；华测须含 #BESTPOSA 且不含 #BESTGNSSPOSA）；不符跳过+弹窗。
- 场景单选（必选）：室外冷启动 / 室内冷启动；室内需两家各 1 个连续文件。
- 切片复选框"一次性录制了 N 次冷启动（自动切片）"，默认不勾。
- 分析按 product_key 分组：同类型一起出报告；多产品时输出到 <out_dir>/<beiyun|huace>/；室内模式调 indoor_coldstart.py。

## 实测室内联合结果（9 次启动 × 2 家 = 18 段）
- 共同 t0 偏移 23~64s；北云首固定 32~198s、华测 10~142s（越往后越快）。
