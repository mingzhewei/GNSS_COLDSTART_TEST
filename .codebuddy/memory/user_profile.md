用户负责 GNSS 接收机冷启动定位收敛的对比测试工作，项目 `gps_test_coldstart` 覆盖三家器件：北云 BY（UG016）、华测 HUACE（M720/M7 系列）、北斗 UM980（和芯星通 N4）。测试形态：室内/室外冷启动、一次性录制 N 次冷启动、多机同时上电配对对比。用户重视：分析口径与协议手册逐字段对应、代码逻辑正确、报告可追溯到手册条款。沟通语言为简体中文。项目代码托管于 GitHub（mingzhewei/GNSS_COLDSTART_TEST）。
